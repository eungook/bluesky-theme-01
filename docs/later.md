# 나중에

지금은 하지 않기로 한 것의 목록. 사람과 에이전트가 같이 읽는다. 지금 정해야 하는 결정은 [pending.md](pending.md)에 적는다.

## 운영 규칙

- 여기에는 두 가지가 들어간다.
  - **보류한 항목**: 사용자가 지금은 정하거나 확인하지 않아도 된다고 한 것.
  - **사용자 할 일**: 에이전트가 할 수 없는 조사나 확인.
- 항목마다 **보류한 날짜**, **다시 꺼낼 조건**, **지금의 상태**, **결과에 따라 바뀌는 것**을 적는다.
- 에이전트는 이 파일의 항목을 "결정 대기"에 올리지 않는다. 다시 꺼낼 조건이 되었을 때만 사용자에게 알린다.
- 해결되면 항목을 지운다. 결정 내용은 해당 문서([extension-guidelines.md](extension-guidelines.md) 등)에 기록한다. (이력은 git에 남는다.)
- 보류한 결정을 다시 정해야 하게 되면 [pending.md](pending.md)로 옮긴다.

## 목록

### `rgb(242, 242, 242)` 배경의 정체 — 사용자 할 일

- **보류한 날짜:** 2026-10-10. 사용자가 지금은 확인하지 않아도 된다고 했다.
- **다시 꺼낼 조건:** 화면에서 흰색 계열인데 톤다운되지 않은 곳이 눈에 띌 때.
- **할 일:** 인라인 배경색 수집에서 `rgb(242, 242, 242)`가 두 번 모두(7곳, 6곳) 나왔지만 어떤 요소인지 모른다. 어느 화면의 어떤 요소인지 DevTools로 확인한다.
- **단서(추정):** 어둑함과 어두움 수집에는 `rgb(1, 1, 1)`이 4곳씩 나왔고 어두운 쪽에는 대응하는 값이 이것뿐이다. 곳 수가 비슷해서(6~7곳 vs 4곳) 같은 요소의 바탕별 값일 수 있다. 확인할 때 두 값을 함께 찾아본다. 근거가 약한 추정이다.
- **현재 상태:** 건드리지 않고 있다. 흰색 계열인지, 톤다운 대상인지 정해지지 않았다.
- **결과에 따라 바뀌는 것:** 대상이면 theme.css에 `--bt-bg-*` 변수와 규칙을 추가한다.

### 추가 자동 테스트 — 사용자 결정

- **보류한 날짜:** 2026-10-14. 사용자가 테스트를 [hover 색 확인](../tests/live/hover-background.test.ts)(라이트와 어둑함)과 [설정 주소 확인](../tests/live/settings-path.test.ts)(로그인 필요)으로 좁혔다.
- **다시 꺼낼 조건:** 사용자가 테스트를 더 늘리자고 할 때.
- **후보:** 확장을 올려 실제로 색이 바뀌는지(Playwright의 Chromium에 `--load-extension`, 정식 Chrome은 불가)와 선택 화면이 뜨는지, 왼쪽 메뉴의 hover, 치환표에 없는 새 인라인 색 감시, 설정 화면의 안쪽 구조(첫 radiogroup의 선택지 3개, 어두운 테마 선택의 위치)와 같은 주소에 "페이지 없음" 화면이 뜨는 경우, `theme--dark`, 가짜 chrome/DOM으로 하는 순수 로직 테스트.

### 어둑함의 구분선 색이 치환표와 다르다 — 확인 필요

- **발견한 날짜:** 2026-10-14. 테스트를 만들려고 실제 화면을 열어 보다가 알았다. (테스트에는 아직 넣지 않았다.)
- **내용:** 로그인 없는 `https://bsky.app/profile/bsky.app`을 `colorScheme: 'dark'`(=`theme--dim`)로 열면 라이트의 구분선 계열 `rgb(220, 226, 234)`(16곳)에 해당하는 요소의 인라인 배경색이 `rgb(57, 73, 96)`(16곳)이다. theme.css의 어둑함 구분선 규칙은 `rgb(44, 58, 78)`만 키로 쓰므로 **어둑함에서 이 요소들은 테마 색으로 바뀌지 않는다.** `44,58,78`은 앞서 수집할 때 3곳 나온 다른 요소의 값으로 보인다.
- **다시 꺼낼 조건:** 다크 모드 테스트에 구분선 확인을 더할 때, 또는 어둑함에서 구분선 색이 안 바뀌는 것이 눈에 띌 때. (다크 hover 테스트는 이미 있지만 hover만 보고 구분선은 보지 않는다.)
- **고친다면:** 어둑함 규칙에 `rgb(57, 73, 96)` → `--bt-bg-100`을 더한다. 요소의 정체(구분선인지)는 확인하지 못했다. 어두움(`theme--dark`)의 값은 아직 실측하지 못했다.
