# 결정 대기

사용자가 정해야 하는 결정의 목록. 사람과 에이전트가 같이 읽는다. 지금은 하지 않기로 한 것은 [later.md](later.md)에 적는다.

## 운영 규칙

- 결정은 두 종류로 나눈다.
  - **막음**: 답에 따라 작업이 크게 달라지거나 되돌리기 비싼 결정. 에이전트는 기본값으로 밀고 가지 말고 **작업 전에 채팅에서 바로 묻는다.** 답이 바로 오지 않으면 이 파일에 적고 해당 작업은 멈춘다.
  - **안 막음**: 틀려도 나중에 고치면 되는 결정. 에이전트는 기본값으로 진행하고, 답변에 "X로 했다, 아니면 말해 달라"를 한 줄로 쓴 뒤 이 파일에 적는다.
- 항목마다 **질문**, **현재 기본값**, **답에 따라 바뀌는 것**을 적는다.
- 결정이 나면 항목을 지우고, 결정 내용은 해당 문서([extension-guidelines.md](extension-guidelines.md) 등)에 기록한다. (이력은 git에 남는다.)
- 사용자가 지금은 정하지 않겠다고 하면 [later.md](later.md)로 옮긴다.
- 작업을 마치는 답변 끝에는 이 파일의 항목을 "결정 대기"로 최대 3개까지, 한 단어로 답할 수 있게 적는다.
- 사람은 새 기능을 시작하기 전이나 큰 커밋 전에 "결정 대기 정리해줘"라고 요청해 이 파일을 점검할 수 있다.
