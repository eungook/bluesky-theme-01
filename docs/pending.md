# 결정 대기

지금 사용자의 답이나 행동이 필요한 것의 목록. 결정과, 작업을 막고 있는 사용자 할 일(조사, 자료 수집)이 들어간다. 사람과 에이전트가 같이 읽는다. 지금은 하지 않기로 한 것은 [later.md](later.md)에 적는다.

## 운영 규칙

- 결정은 두 종류로 나눈다.
  - **막음**: 답에 따라 작업이 크게 달라지거나 되돌리기 비싼 결정. 에이전트는 기본값으로 밀고 가지 말고 **작업 전에 채팅에서 바로 묻는다.** 답이 바로 오지 않으면 이 파일에 적고 해당 작업은 멈춘다.
  - **안 막음**: 틀려도 나중에 고치면 되는 결정. 에이전트는 기본값으로 진행하고, 답변에 "X로 했다, 아니면 말해 달라"를 한 줄로 쓴 뒤 이 파일에 적는다.
  - 화면을 보며 다듬는 값(색, 문구 등)은 결정이 아니라 조정이다. 선택지가 갈리지 않고 사용자가 화면을 볼 때 자연스럽게 피드백하므로 이 파일에 적지 않는다. 답변에서 첫 추정값이라고 한 줄로 알리면 충분하다.
- **사용자 할 일**: 에이전트가 할 수 없는 조사나 자료 수집이 작업을 막고 있으면 여기에 적는다. 막고 있지 않은 할 일은 [later.md](later.md)에 적는다.
- 항목마다 **질문(또는 할 일)**, **현재 기본값(또는 상태)**, **답에 따라 바뀌는 것**을 적는다.
- 결정이 나면 항목을 지우고, 결정 내용은 해당 문서([extension-guidelines.md](extension-guidelines.md) 등)에 기록한다. (이력은 git에 남는다.)
- 사용자가 지금은 정하지 않겠다고 하면 [later.md](later.md)로 옮긴다.
- 작업을 마치는 답변 끝에는 이 파일의 항목을 "결정 대기"로 최대 3개까지, 한 단어로 답할 수 있게 적는다.
- 사람은 새 기능을 시작하기 전이나 큰 커밋 전에 "결정 대기 정리해줘"라고 요청해 이 파일을 점검할 수 있다.

## 목록

### 어두운 쪽 구현에 필요한 자료 — 사용자 할 일 (작업을 막는 중)

- **상태:** 어두운 쪽 적용 방식은 A로 정했다(가이드라인의 "범위 결정"). 어둑함(`theme--dim`)과 어두움의 인라인 배경색 목록이 없어서 구현을 시작하지 못한다. 어두운 쪽은 지금 적용되지 않고, 색상 테마 섹션은 밝은 테마에서만 보인다.
- **할 일:** 블루스카이의 어둑함과 어두움 각각에서 인라인 배경색을 수집해서 알려 준다.
  1. 블루스카이를 색상 모드 "어두움", 어두운 테마 "어둑함"으로 둔다. 페이지를 새로고침한다.
  2. 콘솔에 아래를 붙여 넣는다.
     ```js
     window.__seen = new Map();
     const scan = (el) => { const c = el.style?.backgroundColor; if (c) __seen.set(c, (__seen.get(c) || 0) + 1); };
     document.querySelectorAll('[style]').forEach(scan);
     new MutationObserver((ms) => ms.forEach((m) => scan(m.target))).observe(document.body, { subtree: true, attributes: true, attributeFilter: ['style'] });
     ```
  3. 설정, 프로필, 피드, 알림 등 여러 화면을 돌아다니며 항목 위에 마우스를 올린다. (hover 색을 모으기 위해서다.)
  4. 콘솔에서 `copy(JSON.stringify([...__seen]))`를 실행해 결과를 붙여 넣어 알려 준다. `document.documentElement.className` 값도 함께 알려 준다.
  5. 어두운 테마를 "어두움"으로 바꾸고 1~4를 반복한다. (`theme--dim`은 확인됨. 어두움은 `theme--dark`로 추정한다.)
- **자료로 하는 일:** 어둑함/어두움 각각의 색을 통합 테마별 목표 팔레트로 옮기는 치환표(바탕마다 한 벌)를 만든다. 색상 테마 섹션의 "밝은 테마에서만 표시" 조건을 없애고, 블루스카이의 "어두운 테마" 선택 섹션을 숨긴다.
